# Continentum

**Europe's tech comeback, by Quentin Lestienne.**

Continentum is a newsletter on European tech, sovereignty, defence and innovation, published every two weeks. This repository hosts its landing page.

🌍 **Website:** [continentum.eu](https://continentum.eu)

## What's inside

- `index.html`: the landing page (single file, no build step)
- `og.png`: the preview image shown when the link is shared on LinkedIn or X

## How it works

The page is a static HTML file served by GitHub Pages. Sign-ups go through an embedded Substack form, which handles subscribers and sends each issue by email.
